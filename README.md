# tic-tac-toe
A lightweight, browser-based two-player Tic Tac Toe game created using HTML5, CSS3, and vanilla JavaScript.

## Overview
This project implements the classic 3×3 grid game where two players take turns marking spaces with `X` and `O`. The application tracks player turns, validates moves, detects winning combinations or ties, and allows users to reset the board for a new match.

## Project Structure
- `index.html` — Page structure and game board layout
- `style.css` — Visual styling, grid alignment, and responsive layout
- `script.js` — Game logic, turn management, win/draw checks, and reset functionality

## Getting Started
1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, or Safari).
3. Click any empty cell on the board to begin playing.
